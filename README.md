### Code Review Practice

```Example.java```는 퀴즈에서 확인했던 문제가 있는 코드를 담고 있습니다. 이 실습은 코드 리뷰를 통해 발생가능성이 있는 여러 문제를 확인하는 것입니다. 실습은 다음과 같이 진행합니다.

1. 우선 팀별로 이 저장소를 ```fork``` 하고, 팀원들은 그 저장소를 ```clone```하고, 새 브랜치를 만들어 작업합니다.
2. 실제 코드를 실행해보면 ```abc```를 처리하는 과정에서 에러가 발생합니다.
3. 해당 에러 및 기타 다른 발생 가능한 에러를 고려하여 ```reverse()```를 수정합니다.
4. 이후 PR에서 본인이 수정한 부분에 대해 설명하고 등록합니다.
5. 각자 다른 팀원이 날린 PR을 하나씩 맡아 코드를 리뷰하고, 예상되는 문제점 - 예를들어 제대로 처리 못하는 에러발생 가능성 - 에 대해 설명합니다.
6. 각 팀원은 지적사항에 대해 수정한 커밋을 작성하여 PR에 통합합니다.
7. 문제가 없으면 해당 PR을 ```merge```합니다.
